# 📊 Modstar Tom Ford Sales Analytics – Excel Dashboard

## 📌 Project Overview

This project is an automated **Retail Sales Analytics and MIS Reporting System** developed using Microsoft Excel.

The report is designed to analyze sales performance at multiple levels, including:

- Monthly sales
- Daily sales
- SKU-wise sales
- Model-wise sales
- Store-wise sales
- Staff-wise sales
- MRP and Cost analysis
- Discount analysis
- Tax analysis
- Lens value analysis
- Sales margin analysis
- Sales incentive calculation

## 🎯 Business Objective

Retail businesses generate a large amount of transactional sales data every day.

Manually analyzing this data can be time-consuming and can lead to reporting errors.

This Excel project automates important calculations and provides a structured reporting system that helps management understand:

- Which models are selling the most
- Which SKUs are performing better
- Which stores are generating higher sales
- Which staff members are contributing more sales
- Discount impact on sales
- MRP vs Cost performance
- Gross sales and net sales
- Margin contribution
- Incentive payable to eligible sales
- Monthly sales trends
